## What changed
- Added add-only tables `RolePermission` and `AccountAuditLog` (migration `20261029200000_add_role_permission_and_account_audit`). Applied only to the local throwaway database `fu_session_test`.
- The server checks a named permission after sign-in. Defaults: sending a NERIS report (`neris.export`) is admin, sending a NERIS report for billing (`billing.submit`) is admin, and creating or editing an incident by hand (`incidents.create`) is admin.
- Saving department settings no longer creates, edits, or deletes accounts.

- Admin Functions → Department Details → Department Access shows “Who can do what.” Create Incident and Send to Fire Recovery hide when the signed-in person lacks permission. A failed incident update or delete no longer writes the change into the browser anyway.
- `super_admin` is treated as superadmin when the server reads a role.
