## What was built
- `Session` table (fingerprint, department, person, signed-in time, last active, expires, cancelled). Migration `20261029180000_add_session`. Applied only to a throwaway local database during tests.
- `server/auth/sessions.mjs` and a sign-in check in front of every `/api` route except login, tenant context, CAD inbound email, and `/api/admin`.
- Login sets an HttpOnly, SameSite=Strict, host-only cookie with no expiry date in the browser (session cookie). Secure is on except for localhost.
- Role comes from `User.role` on every request. Department "user type" labels no longer decide the role at login.
- Change-password uses the signed-in person and cancels that person's other passes. Password reset and a changed password cancel passes. Deleting an account removes its passes.
- Frontend asks the server who is signed in on load, shows a sign-in box over the current screen when a pass is refused, and clears cached department data on logout.
